# Changelog

All notable changes to this project will be documented in this file.

## [v0.2.0] - 2026-09-23
### Added
- Live terminal demonstration block in README.
- PyPI packaging configuration (`envdoctor`) with zero runtime dependencies.
- Subcommands for `check` (discrepancy linter), `sync` (safe automated migration), and `audit` (source code AST variable scanner).
- Full GitHub Composite Action support.
